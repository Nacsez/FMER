# FMER 734 — video planning drafts

These are recording plans, not claims that a demonstration has been captured.
Use the actual unit and record its direct audio. The annotated guide is an insert
for explanations; its waveform fixtures must not be substituted for live sound.
Keep the same dark background, green control labels and pink pointers throughout.
Leave a short clean audio-only passage after each change so viewers can hear it.

## 1. The overview — 75 seconds

| Time | Picture / action | Suggested narration |
|---|---|---|
| 0–8 s | Wide shot; play a short FM phrase. Show 734 identity briefly. | “This is FMER on the M-VAVE FM-1.” |
| 8–20 s | FM algorithm diagram, then a VA phrase at a comparable level. | “Six-operator FM and Virtual Analog, with detailed editing on the instrument.” |
| 20–30 s | ENV+HOME for glide; LFO+HOME for a chord. | “One voice with glide, or four voices for a single sound.” |
| 30–45 s | HOME+SEQ. Add four prepared mono parts with mute and volume. | “Four-track mode gives each part its own sound and pattern.” |
| 45–55 s | SEL+SEQ. Show a transposed entry and repeat blocks. | “Arrange those patterns with repeats and transposition.” |
| 55–65 s | FX routing and full-screen HOME. | “Rearrange the effects, then expand the visual feedback.” |
| 65–75 s | Companion library and handbook. End on version and feedback invitation. | “Organize and back up locally with FMER Companion. Public testing starts before 1.0.” |

Preparation: save separate examples for each mode. Mode transitions involving 4T
stop playback, so use explicit edits between scenes. Do not imply a seamless
mode change. Use the playing-modes, mixer, song and FX-routing sheets as inserts.

## 2. One phrase, two engines — 2 to 3 minutes

1. Play the same unprocessed phrase on an FM keys sound and a VA saw sound.
   “Two approaches to the same phrase.” Keep output levels comparable.
2. FM: hold a note, show the algorithm overlay, adjust a modulator's level and
   envelope. “The modulators change the spectrum; carriers reach the output.”
3. Show ENV, then EDIT / OP RATES. Explain joint carrier shaping versus individual
   operator editing. Do not call FM rates milliseconds.
4. VA: switch waveform, sweep the voice filter, adjust attack and release.
5. Add a little reverb. Let the tail decay; show dry and processed states.
6. Save each variation into a USER slot. “The factory loadout is a starting point.
   Either engine can occupy either bank.”

Inserts: FM synthesis, algorithms, FM envelopes, Virtual Analog, instrument banks.
Close with a 10-second uninterrupted performance, using the real unit's audio.

## 3. A chord becomes a pattern — 90 seconds

| Time | Action | Explanation |
|---|---|---|
| 0–20 s | Enable arp; hold a chord. Compare Played and Strum. | “The arp uses the notes you supply.” |
| 20–35 s | Set rate, gate and swing. Show triplets separately. | “Timing is on the second page.” |
| 35–50 s | Select an empty destination beforehand; REC from ARP. Show all four lead-in beats. | “This captures the generated notes.” |
| 50–65 s | Finish the take; stop supplying the chord and replay the pattern. | “Now the phrase exists as editable pattern data.” |
| 65–90 s | Open NOTE EDIT, move one note and extend another. | “Change the result without performing the whole part again.” |

Check the selected project, pattern and Overdub/Replace mode before recording.
Capture the true metronome/downbeat; do not retime the video to conceal a timing
problem. Inserts: arp, recording, note edit.

## 4. Four tracks as a live instrument — 2 minutes

Prepare kick, snare, bass and lead parts with separate saved instruments. Open the
mixer using HOME+SEQ. Start playback. “Each knob belongs to one track. The selected
layer decides what it edits.” Show Volume, Mute, Solo and FX one at a time.

Switch the Pattern layer and queue a change. Show the pending indicator and let
the boundary occur in the same shot. Demonstrate the selected-track next-bar
shortcut, then the all-track shortcut. “A queued action waits for the next
16-step bar.” Show FX, then return with a long SEQ press. Finish on the five traces
in expanded HOME. Explain that the four part traces precede faders/FX, while the
master trace shows the final output. Inserts: mixer, scopes, shortcuts.

## 5. Repeats and transposition — 2 minutes

Build a short, easy-to-follow bass pattern. Enter Song and add three entries:
pattern 0 / transpose 0 / repeats 2, pattern 0 / transpose +5 / repeats 1,
pattern 1 / transpose 0 / repeats 1. “Reuse the pattern; change its role in the
arrangement.” Show the duplicate repeat blocks and current entry while it plays.

In 4T, show a drum lane alongside it. Explain that lanes share time but may have
different entry lengths. Show Loop versus Stop. Save the instruments and project.
Conclude: “There are 32 entries per lane, with up to 32 repeats for each entry.”
Inserts: song, data map, sound-to-song workflow.

## 6. Effects order, heard clearly — 90 seconds

Use one harmonically rich sound and a short repeated phrase. Show the six-stage
chain. Compare drive before versus after the filter, then delay and reverb order.
Keep gain changes under control and identify the actual chain on each take.

“K1 selects a stage. K2 moves it. K3 recalls my saved order.” Demonstrate a saved
personal default with playback stopped: hold SEL and press FX. Explain the
separate GLO reset to original routing. End with the same phrase dry, then with
the chosen chain. Inserts: filter, delay, reverb, FX routing.

## 7. Two units, one clock — 90 seconds

Show both units powered, their USB cable and no computer connection. Configure
Master / Clock on one and Receiver on the other; press SEL to apply. “Each unit
keeps its own sounds and patterns.” Start, pause and restart from the leader in
an uncut shot. Demonstrate Notes or Both in a separate passage if desired.

End by switching both to PC/NORMAL before connecting Companion. Say explicitly:
“This is a direct wired pair. Bluetooth groups are future work.” Do not imply
USB audio flows between the units. Insert: paired USB workflow.

## 8. Install, save, recover — 3 to 4 minutes

Start with a fresh extracted portable folder on a second Windows computer.
“Everything runs locally. Extract the entire ZIP, then open FMER Companion.”
Show connection status, a supported-FMER backup, firmware inspection and progress.
If using stock, state that its musical bank backup interface is unavailable.

Keep the install progress visible; a time-lapse must carry “time-lapse” text.
Wait for completion before touching the unit. Then show a library import, a
clearly selected destination, a verified transfer, the visual guide and feedback
export. Explain that private ROMs and complete AppData folders should not be
posted publicly. The application restores supported original firmware only from
a separately supplied compatible image; do not imply a bundled factory reset.

## Short-form alternatives — 15 to 30 seconds each

- One chord, three arp types, with type labels matching the screen.
- Filter LP → HP → BP, with the same signal and visible fill direction.
- “Two buttons to the mixer”: show HOME+SEQ, then the four faders.
- A note moved in time without recording again.
- Reverb tails: Room, Plate, Hall, Cloud, each with silence to hear decay.
- “Save the sound, save the song”: the two SAVE scopes and a Companion backup.
- HOME expanded scope, followed by the matching uninterrupted audio.

## Recording checklist

Record build number, instrument/project slots, direct audio path and clock source
in a take log. Back up the demonstration project first. Show controls legibly and
avoid filming button presses behind the hand. Use original or cleared music.
Preserve raw takes and note any edits. A tutorial should show successful observed
behavior; retain failures as QA evidence rather than editing them into a claim of
reliability. The owner chooses final tone, duration and publication channel.
