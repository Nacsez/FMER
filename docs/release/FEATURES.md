# FMER 734: feature tour

Production-rendered firmware screens and isolated Companion captures. Musical states and waveforms are illustrative. Pink pointers identify controls; the underlying screens are unchanged. Download the PDFs or open the offline handbook for workflows and the complete parameter reference.
