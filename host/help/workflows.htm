Examples

Practical workflows

From a standalone bass patch to a backed-up live set.

A standalone instrument

  1. Select a DEFAULT or USER sound by scrolling PRESETS across the banks.
  2. Edit its engine, envelope and effects.
  3. Save it into an instrument slot. Use USER for a personal working collection.
  4. Recall it once to verify the intended destination before disconnecting.

A four-part sketch

  1. Save four instruments and assign kick, snare, bass and lead to tracks 1–4.
  2. Record or hand-edit four patterns. Use ties for held notes and rests for silence.
  3. Mix in PERFORM, then queue variations at pattern boundaries.
  4. Save a project and make a complete unit backup when connected.

A portable library collection

  1. Capture useful instruments and projects into the companion Library.
  2. Name and tag them; collect a live set under one collection label.
  3. Export the selection. Include a complete unit backup if slot references must be preserved exactly.
  4. On another installation, import the catalog and deliberately assign destination slots.

Recover a mistake

For an immediate local edit, use its Undo. For a trashed item, use Recover. For a larger local change, restore an exported catalog or PC bank backup. Device writes are separate: inspect the retained pre-operation backup and restore plan, then explicitly restore the required data.
