Sound & session

An original one-carrier INIT voice. Imports are decoded before controls change.

Lab sessions keep this sound, effects, pattern, arp and phrase settings. Standard DX7 export contains the FM voice only; VA, effects, pattern and app settings are omitted. Neither format is an FM1 device backup.

Move a slider or choose a labeled value. Exact core values remain visible and editable beside every control. Pink outlines show keyboard focus; green marks the active choice.

Effects

Shared FM / VA effects. Zero amounts bypass each effect. The output lowpass works on both engines. These are original FMER implementations, not a measured reproduction of another firmware.

Step pattern

One internal lane · 16th-note steps · up to nine notes per step. Shortening the pattern preserves its hidden steps. Dashes are rests; a tie sustains the preceding chord.

Step 1

Tap notes to build a chord · maximum nine notes

Notes and velocity sliders apply immediately. A tie clears this step's notes and sustains the previous chord. Undo restores one complete gesture.

Advanced note entry

Use comma-separated MIDI pitches, or pitch:velocity, for example 60:100,64:85,67:90. These fields apply when you press Apply step.

Arpeggiator

Arpeggiates the phrase's major chord. Inclusive repeats turnaround notes; Exclusive does not. Enable halfway release to compare latch behavior. Each render restarts from its seed.

Companion library

128 local slots persist on this computer. Audition opens a temporary sound. Only explicit Save, bank import or Restore changes saved slots. The library is a host companion prototype, with no device connection.

Manage 32-voice DX7 banks

First import a bank in Sound & session. Save imported bank writes its original 32 decoded voices starting at the selected library slot; temporary editor changes are separate. Export requires 32 occupied slots and omits VA, effects and patterns.

Loading local library…

Save replaces the selected slot. Restore replaces the whole local library after validation; the previous version is retained for Undo. Keep downloaded backups for longer history. Standard DX7 voice export above deliberately omits extension data.

Testing this build

Render requests, event traces, browser actions and errors are kept in local artifacts, so a problem can be traced without copying console messages. Source and render identities appear in the report. Hardware timing, USB/BLE, tiny-screen pages and stock/Baud sound parity remain separate work.

A saved library sound or lab session is the best way to keep a reproducible test case. Stop audio is always available while a render is in progress.
