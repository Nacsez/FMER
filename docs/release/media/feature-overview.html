Two synthesis engines

Six-operator FM, 32 algorithm diagrams and DX7-style interchange. Virtual Analog with sine, saw, square, triangle and noise.

Three ways to play

1V glide, 4V polyphony or four mono parts in 4T. Four simultaneous voices total.

128 instrument slots

64 editable defaults and 64 independent user sounds. Either engine in either bank; original defaults start with 32 FM and 32 VA.

Six reorderable effects

Filter, reverb, delay, chorus, phaser and drive. Four reverb models, beat-synced delay and stored personal routing. LFO modulation stays with the sound.

Arpeggios into patterns

11 types including Strum. Latch, octave range, triplets, gate and swing. Record the generated notes into a pattern.

A portable arrangement

16 projects; 16 patterns per project, up to 64 steps each. Four song lanes with 32 entries per lane, repeats and transpose. Single-instrument sequencing too.

Hands-on performance: per-track level, mute, solo, FX routing, patch, pattern and run state. Next-bar launches, live waveform views and panel shortcuts.

Your sounds. Your instrument.

FMER Companion organizes instruments, projects and backups on your own computer. The portable Windows package includes the runtime, installer, firmware, default library and illustrated offline handbook.

Local from the start

  1. Extract the complete Windows ZIP.
  2. Launch FMER Companion.exe.
  3. Connect one FM-1 and check connection.
  4. Back up, then inspect and install firmware.

Wired into your setup

USB MIDI notes, clock and documented controls. Split or merge outgoing track channels. Direct USB links pair two powered FMER units. TRS MIDI accepts input.

Scope: Windows 10/11 x64. Shared effects; combined USB audio, no separate stems. Battery percentage is estimated. Bluetooth and macOS/Linux binaries are deferred. Compatibility checks protect supported layouts; unknown layouts cannot be forced.

Original FMER code, defaults and splash: GPL-3.0-only. Board support: Felucca. FM foundation: MSFA. Updater foundation: SLOOP. See the included notices.
