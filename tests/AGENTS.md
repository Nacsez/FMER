# Agent guidance

Read the root AGENTS.md and CONTRIBUTING.md first. Beta testers should use the published companion and submit optional feedback/diagnostic summaries through issues, not unsolicited pull requests. Code contributions require explicit prior maintainer permission; project direction remains with the owner. Do not publish, push, upload logs or flash hardware merely because you can access it; follow the user's explicit task and existing authorization.

Original FMER firmware, Companion and original default patches are GPL-3.0-only (see root LICENSING.md). Preserve all existing third-party licenses, attribution and dependency provenance. Do not blanket-relicense the corpus, artwork, stock images or imported banks. Keep private ROMs, unlicensed stock payloads, personal media, AppData, keys and local libraries out of git and release assets. Never claim universal flashing compatibility or offer force/unguarded writes.

Use observable regression tests and isolated user data. Never open MIDI or flash real hardware from the default test suite. Test failure paths and preservation, not just successful calls.
