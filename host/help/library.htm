Companion

Library, collections and Trash

Keep a larger catalog of instruments and projects independently of the unit's slots.

Library holds up to 512 items, subject also to a 10 MiB file limit including Undo history. Each item has a unique identity, instrument/project type, title up to 80 characters, collection, up to 12 distinct tags of 24 characters, notes up to 1,000 characters and a favorite flag. A collection is a label, not a folder path.

Search and type/collection filters narrow the list. Select several items to move them into a collection, duplicate them, export them or send them to Trash. Duplicate creates an independent item. Editing its title does not rename a hardware slot. An instrument's separate ten-character name is stored inside its sound record.

Trash hides items from the normal library. Recover returns them; Empty Catalog Trash permanently removes the currently trashed items from the catalog. Export first if you need a lasting archive. Undo reverses one catalog transaction. It is not a history of all changes and does not reverse device writes.

Import merges a catalog file using new item identities. Restore Local Catalog replaces the local catalog after explicit confirmation; it leaves PC banks and the FM-1 alone. Catalog checksums detect accidental alteration. Writes use a lock, revision check and atomic replacement, retaining the previous file and operation journal.

Prepare a live set

  1. Select the relevant instruments and projects.
  2. Move them to a collection named after the set.
  3. Add song/order tags and mark favorites.
  4. Export the selection as a portable catalog file.
  5. Back up the unit before assigning these sounds to hardware slots; projects reference slot numbers.

Exchange FM sounds with DX7-compatible editors

  1. In Felucca's FM6 editor, export the desired sound as standard DX7 .syx, or use an existing DX7 single voice or32-voice bank you have permission to use.
  2. In FMER Companion Library, choose Import DX7 FM and select the .syx file. The importer validates framing, checksum and parameter ranges before changing the local catalog.
  3. Review the decoded sounds, then import. A single voice adds one instrument; a bank adds32. Import is one local transaction and can be undone. No unit is written automatically.
  4. Open an imported instrument in Editor to audition and adjust it. Imported voices start with dry FMER effects. Use Prepare unit transfer when you deliberately want to write a hardware slot.
  5. To send voices back, select exactly one or32 FM instrument items and choose Export DX7 FM. Exporting creates a local .syx download. VA instruments and projects are refused.

Supported files are one163-byte single-voice message or one4104-byte32-voice bank. Export preserves the six-operator FM parameters and ten-character name; FMER effects, VA controls, patterns, songs and globals are outside DX7 SysEx. Felucca native JSON/project/other engines are different formats and are not imported. A shared patch does not guarantee identical sound across different synth implementations.

Rename and deploy a set

  1. Select an item. Set Instrument name on unit (1-10 printable ASCII characters) and choose Save name & details. The longer Library title is for this computer only.
  2. Select the sounds to deploy and choose Send selected to unit. Choose each destination in the review table, or use Place in Bank B/Bank A, Starting slot and Place consecutively to position an instrument set in one action. The start selector prevents crossing the bank boundary. Project bundles retain individual reference-based destinations.
  3. Review names and slots, then confirm. Companion backs up the complete unit before writing and verifies each slot. On success it downloads that backup and restores the working state with playback stopped.

Import file also accepts an FMER PC sound-bank JSON file: it merges populated sounds into the Library as independent copies, with one Undo. It does not replace the PC banks or write the unit. Get updates & sound packs opens GitHub in your browser. Download the original default catalog separately or import it from the portable ZIP's Libraries folder.
